# 🎬 Mad Movies

Mad Movies is a dynamic movie browsing web application built using PHP, MySQL, JavaScript, and jQuery. The platform fetches movie data from a structured database and displays it through an interactive and user-friendly interface.

## 🚀 Features
- Dynamic movie listings from database
- Real-time search functionality
- Filter system for better navigation
- Responsive and clean UI
- Smooth frontend interactions

## 🛠 Tech Stack
- PHP
- MySQL
- JavaScript
- jQuery
- HTML & CSS
